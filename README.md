# blinkit-sales-analysis
## Blinkit Sales Analysis Using Python

## Project Overview

This project analyzes Blinkit's sales performance, customer ratings, product categories, and outlet distribution using Python. Pandas, Matplotlib, and Seaborn are used to clean, analyze, and visualize the data to identify business insights.

## Business Objective

To analyze sales performance, customer satisfaction, and outlet characteristics to identify opportunities for business optimization.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Key Performance Indicators (KPIs)

1. **Total Sales:** Overall revenue generated from all items sold.
2. **Average Sales:** Average sales value, as defined by the dataset and analysis.
3. **Number of Items:** Number of items sold or item records, depending on available data.
4. **Average Rating:** Average customer rating across the available records.

## Data Analysis and Visualizations

### 1. Total Sales by Fat Content

* Chart: Donut/Pie Chart
* Objective: Compare sales for Regular and Low Fat products.

### 2. Total Sales by Item Type

* Chart: Bar Chart
* Objective: Identify the item categories contributing the most sales.

### 3. Fat Content by Outlet for Total Sales

* Chart: Stacked Column Chart
* Objective: Compare outlet sales segmented by fat content.

### 4. Total Sales by Outlet Establishment Year

* Chart: Line Chart
* Objective: Analyze sales patterns by outlet establishment year.

### 5. Sales by Outlet Size

* Chart: Pie Chart
* Objective: Compare sales contributions from different outlet sizes.

### 6. Sales by Outlet Location

* Chart: Horizontal Bar Chart
* Objective: Compare sales across outlet location tiers. A geographic map can be used if suitable location data is available.

## Python Libraries Used

* **Pandas:** Data cleaning, grouping, and aggregation.
* **NumPy:** Numerical operations.
* **Matplotlib:** Data visualization.
* **Seaborn:** Statistical and categorical visualizations.

## Key Business Questions

* Which fat-content category generates the most sales?
* Which item types perform best?
* How do sales vary by outlet and fat content?
* How do sales vary by outlet establishment year?
* Which outlet size contributes the most sales?
* Which outlet location tier performs best?

## Project Structure

* `data/`: Dataset files, if redistribution is permitted.
* `notebooks/`: Python analysis and visualization notebook.
* `images/`: Screenshots of generated charts.
* `requirements.txt`: Required Python libraries.

## How to Run the Project

1. Clone or download this repository.

2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebook:

   ```bash
   jupyter notebook
   ```

4. Open `notebooks/blinkit_analysis.ipynb` and run the cells.
